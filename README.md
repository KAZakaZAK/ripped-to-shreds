# Ripped to Shreds

Proof of concept for a second-hand punk boutique web store. Not a live site.

## Layout

- `index.html`, `shop.html`, `product.html` Styled design (home, shop, product). Static HTML, CSS and JS.
- `site.css`, `design.js`, `tex-dark.png` Design styles, behavior and speckle texture.
- `wireframe/` Structure-only wireframe, 20 pages. Start at `wireframe/index.html`.
- `design-source/` Original Claude Design boards (`*.dc.html`). They need the Claude Design viewer to render.
- `404.html` Page not found.

Nav items on the styled pages that are not designed yet (drops, bands, trade, about, contact, cart, search) link to the matching wireframe page.
